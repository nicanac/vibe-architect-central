## 🔍 How to Find Information "Easily"

To retrieve the best context, use **Concept-Based Queries** rather than keyword searches.

### 1. Finding Tech Specs
*Use specific version numbers to filter out legacy advice.*
- **Query**: "Next.js 16.1 App Router layouts" (not just "layouts")
- **Query**: "Tailwind 4.1 theme variables" (not just "tailwind config")

### 2. Finding Patterns
*Ask for "Patterns" or "Examples".*
- **Query**: "Supabase Server Action pattern for mutations"
- **Query**: "shadcn/ui composition pattern"

### 3. Finding Project Specifics
*Reference the project name or specific files.*
- **Query**: "Vibe Architect Central folder structure"
- **Query**: "MeetFlow AI database schema"
