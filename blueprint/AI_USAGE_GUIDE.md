# AI Agent Usage Guide

This project is supercharged with AI workflows. Use these slash commands to accelerate development.

## 🚀 Core Workflows

- **/new-feature**: Implement a feature (Read `TASKS.md` -> Plan -> Code).
- **/debug**: Fix errors/bugs with systematic analysis.
- **/review-code**: Get expert feedback on your code.
- **/commit-fast-conventional**: Generate conventional commits.
- **/explore-docs**: Research library docs (e.g., Expo, Supabase).
- **/ux-ui-fix**: Fix UI glitches or improve UX.

## 🧠 Memory Bank

The AI maintains context in `memory-bank/`.
- **Always read** `PRD.md` and `TSD.md` before starting big tasks.
- **Update** `TASKS.md` as you progress.
- **Respect** `.agent/rules/architecture.md`.

## 🛠️ Setup

1. Allow valid tools (terminal, file read/write).
2. Ensure `.env` is set up with Supabase keys.
3. Run `npm start` (Expo) to begin.
