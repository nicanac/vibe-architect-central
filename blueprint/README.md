# MeetFlow AI Blueprint

This is the generated blueprint for MeetFlow AI, a mobile meeting assistant.

## Tech Stack
- **Mobile**: React Native (Expo SDK 54)
- **Routing**: Expo Router
- **Backend**: Supabase
- **Visuals**: Purple Gradient / Clean UI

## Usage
1. Run `./scripts/init-project.sh` to scaffold dependencies.
2. Follow `docs/SETUP.md` for env config.
3. Start coding using `/new-feature`!

## Structure
- `.agent/`: AI Agent workflows & rules.
- `app/`: Source code (screens).
- `components/`: UI components.
- `memory-bank/`: Project documentation source of truth.
